**บทเรียน:** `.gitignore` กันได้แค่ GitHub — **ไม่ได้กันการ deploy** ต้องกันที่ `firebase.json` อีกชั้น

### สิ่งที่แก้

| แก้อะไร | ไฟล์ |
|---|---|
| กัน `config.local.js` + `config.local.example.js` ออกจาก hosting | `prototype/firebase.json` |
| สร้างตัวหาคีย์ที่ไม่ฝังคีย์ลงเว็บ (sessionStorage → ไฟล์ในเครื่อง → ถามผู้ใช้) | `prototype/public/ai-key.js` (ใหม่) |
| ปุ่ม AI ทั้ง 2 จุดเรียก `getOpenRouterKey()` แทน import คีย์ตรง ๆ | `formula-new.html`, `formula-detail.html` |
| ลืมคีย์อัตโนมัติเมื่อ OpenRouter ตอบ 401/403 | `forgetOpenRouterKey()` |
| แก้บันทึกเดิมที่ระบุว่า "ตั้งใจปล่อยให้ deploy" ให้ตรงกับความจริงใหม่ | `Submission-RAISE-M2-HW3/README.md` |

**ยืนยันหลัง deploy:** `/config.local.js` → 404 ทั้งโดเมน `.web.app` และ `.firebaseapp.com` ·
ไฟล์ที่เสิร์ฟอยู่ทั้ง 7 ไฟล์ไม่มีคำนำหน้าคีย์ OpenRouter เหลืออยู่เลย ·
ตรวจซ้ำในเบราว์เซอร์จริงแล้วว่า `import("/ai-key.js")` สำเร็จ และ `import("/config.local.js")` ล้มเหลวตามที่ตั้งใจ

**ยังเหลือ:** คีย์ยังไปถึงเบราว์เซอร์ผู้ใช้อยู่ (ผู้ใช้วางคีย์เอง) — ทางแก้จริงคือย้ายไปฝั่งเซิร์ฟเวอร์
