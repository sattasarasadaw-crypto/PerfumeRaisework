## 1. บริบท / ช่องว่างที่พบ

[[20260818-01-ai-perfumery-core|เอกสาร spec หลัก]] หมวด 2 นิยามบทบาท **Formulation Manager** ว่า "ดูภาพรวมโปรเจกต์ ต้นทุน และสถานะ Compliance ของหลายสูตร" แต่เมื่อตรวจทั้งเอกสาร (FR-01–FR-39, `feature-list.md`, `user-journey.md`, `api-spec.md`, `db-spec.md`) ไม่พบ operation, entity, feature หรือ journey ใดที่รองรับมุมมองข้ามสูตร/ข้ามบัญชีเลย — บทบาทนี้จึงมีอยู่แค่ใน "คำนิยาม" แต่ไม่มีระบบรองรับจริง

ปัญหาสำคัญกว่านั้นคือมุมมองข้ามสูตรลักษณะนี้ **ขัดกับ NFR-09** ("สูตรของผู้ใช้ถือเป็นความลับทางการค้า ต้องเข้ารหัสขณะจัดเก็บ และแยกการเข้าถึงตามบัญชีอย่างเด็ดขาด") โดยไม่มีการ reconcile ไว้ในเอกสารใดเลยว่า Formulation Manager จะเห็นข้ามบัญชีได้อย่างไรโดยไม่ละเมิดกฎนี้

**การตัดสินใจร่วมกับผู้ใช้จริง (ยืนยันแล้ว):** ขอบเขตของ Formulation Manager จะถูกจำกัดให้เห็นได้เฉพาะสูตรที่อยู่ใน **บัญชี/องค์กรเดียวกัน** กับตนเท่านั้น ไม่ข้ามไปยังบัญชี/องค์กรอื่น — เป็นข้อยกเว้นเดียวที่ได้รับอนุญาตต่อ NFR-09 ไม่ใช่การเปิดมุมมองข้ามบัญชีแบบไม่จำกัด (global) และไม่ใช่การให้สิทธิ์แบบ per-case grant

## 2. ข้อกำหนดเชิงฟังก์ชันใหม่ (Functional Requirements เพิ่มเติมต่อ [[20260818-01-ai-perfumery-core]] §2)

> ระดับความสำคัญ: **กลาง** — เพราะบทบาทนี้เป็นมุมมองสรุป/รายงานที่ "เพิ่มคุณค่ามาก" ให้กับผู้บริหารโปรเจกต์ แต่ flow หลักของ Perfumer (สร้างสูตร → คำนวณ → ตรวจ Compliance → ตัดสินใจ) ยังทำงานได้ครบโดยไม่ต้องมีมุมมองนี้ก่อน จึงไม่จัดเป็น MVP ระดับสูงเช่นเดียวกับ Engine A/Compliance core

| รหัส | ความต้องการ | รายละเอียด | ระดับ |
|---|---|---|---|
| FR-42 | มุมมองภาพรวมหลายสูตรสำหรับ Formulation Manager | Formulation Manager ดูภาพรวมสถานะของสูตรทั้งหมด **เฉพาะที่อยู่ในบัญชี/องค์กรเดียวกัน** กับตนเท่านั้น ครอบคลุมอย่างน้อย: ชื่อสูตร/เจ้าของสูตร, ต้นทุนโดยประมาณ (อ้างอิง FR-36), สถานะ Compliance ล่าสุด PASS/FAIL (อ้างอิง FR-22) ของแต่ละสูตร — **ห้ามเห็นสูตรของบัญชี/องค์กรอื่นโดยเด็ดขาด** ไม่มีข้อยกเว้น | กลาง |

## 3. ผลกระทบต่อ NFR-09 (ข้อเสนอ — ยังไม่แก้ไฟล์ NFR ในงานนี้)

ตามที่ผู้ใช้ยืนยัน การอนุญาตให้ Formulation Manager เห็นข้ามสูตรภายในขอบเขตบัญชี/องค์กรเดียวกัน คือข้อยกเว้นเดียวที่อนุญาตต่อ NFR-09 จึง**เสนอ**ปรับถ้อยคำ NFR-09 ดังนี้ (บันทึกเป็น dependency ให้รอบ `nfr-review.md`/ทีม NFR review ตัดสินใจแก้ไฟล์จริงในขั้นตอนถัดไป — **ไม่แก้ `20260818-01-ai-perfumery-core.md` ในเอกสารนี้** ตามขอบเขตงานที่กำหนด):

> **เดิม:** "สูตรของผู้ใช้ถือเป็นความลับทางการค้า ต้องเข้ารหัสขณะจัดเก็บ และแยกการเข้าถึงตามบัญชีอย่างเด็ดขาด"
>
> **ข้อเสนอแก้ไข:** "สูตรของผู้ใช้ถือเป็นความลับทางการค้า ต้องเข้ารหัสขณะจัดเก็บ และแยกการเข้าถึงตามบัญชีอย่างเด็ดขาด **ยกเว้นบทบาท Formulation Manager ที่เข้าถึงได้เฉพาะสูตรภายในบัญชี/องค์กรเดียวกันเท่านั้นตาม FR-42 — ห้ามขยายข้อยกเว้นนี้ไปยังบทบาทอื่นหรือข้ามบัญชี/องค์กรโดยไม่มีการอนุมัติและปรับ NFR-09 เพิ่มเติม**"

## 4. Business Rule เพิ่มเติม

- **BR-08** มุมมองข้ามสูตรของ Formulation Manager (FR-42) ต้องจำกัดอยู่ภายในขอบเขตบัญชี/องค์กรเดียวกันเท่านั้น ถือเป็นข้อยกเว้นเดียวที่ได้รับอนุญาตต่อ NFR-09 — ห้ามขยายเป็นการเข้าถึงข้ามบัญชี/องค์กรอื่นโดยไม่มีการอนุมัติเพิ่มเติม
