## 3. สิ่งที่กดได้จริง (Interactive Elements)

| # | สิ่งที่ทำได้ | สาธิต FR/NFR อะไร |
|---|---|---|
| 1 | **แก้ % ของสารแต่ละตัว** — ผลรวมอัปเดตทันที | FR-01 |
| 2 | **ผลรวม ≠ 100%** → ตัวเลขเป็นสีแจ้งเตือน + แสดง "ขาดอีก X%" / "เกินมา X%" + **ปุ่มคำนวณถูกปิด** | FR-02, AC-01.2, AC-01.3 |
| 3 | **กดปุ่มคำนวณ** → Dashboard ปรากฏครบทุกส่วนทันที | FR-26, AC-07.1 |
| 4 | **แก้ % หลังคำนวณแล้ว** → ทุกอย่างคำนวณใหม่**อัตโนมัติ ไม่ต้องกดปุ่มซ้ำ** | FR-21, NFR-02, AC-05.3 |
| 5 | **ดันสารเกินเพดาน IFRA** (เช่น Citral > 3.0%) → เปลี่ยนเป็น **FAIL** + ชี้ชื่อสาร + ส่วนต่าง + **ช่องกรอกขึ้นขอบแดง** | FR-21, FR-22, AC-05.2 |
| 6 | **เมื่อ IFRA FAIL** → **ปุ่ม Export ถูกปิด** พร้อมแสดงเหตุผล | BR-02, AC-05.4 |
| 7 | **ปรับให้ทุกกลุ่มอยู่ระหว่าง 5–20%** → แจ้งเตือน **Muddy Accord** + ค่าความเสี่ยง % | FR-23, BR-04, AC-06.1 |
| 8 | **กด "ขอคำแนะนำปรับลด"** → เปิดกล่องบอกว่าควรดันกลุ่มไหนขึ้น/ลง | FR-24 |
| 9 | **กดที่ค่า Longevity / Sillage** → เปิดกล่อง**อธิบายที่มาของการคำนวณ** | NFR-08, AC-07.4 |
| 10 | **สลับโทนบรีฟ** 3 แบบ (เชิงเคมี / การตลาด / English) | FR-18 |
| 11 | **กด chip ใน Command Bar** หรือพิมพ์คำถาม → แสดงตารางเจาะลึก | FR-29 |
| 12 | **กด "ดูทั้งหมด 100 กลุ่ม"** → แสดงรายการกลุ่มทั้งหมดที่สูตรแตะ | FR-28 |

## 4. สถานะเริ่มต้นของข้อมูลสาธิต

| ค่า | สถานะ |
|---|---|
| ผลรวมสัดส่วน | **100.0%** พอดี (คำนวณได้ทันที) |
| IFRA | **PASS** — สารที่ใกล้เพดานที่สุดคือ Citral (เหลือระยะห่าง 0.60%) |
| Muddy Accord | **ไม่เข้าเกณฑ์** — กลุ่มเด่นสูงสุด Woody Amber ~36.6% (> 20%) |
| สารที่ถูกตัดด้วย ODT | **3 ตัว** — RM-077, RM-081, RM-092 (ตรงกับชุด TD-05 ใน Test Case) |
| Longevity | ~8.0–9.6 ชั่วโมง |
| Sillage | moderate |

### วิธีลองสถานะอื่น

| อยากเห็น | ทำอย่างไร |
|---|---|
| **IFRA FAIL** | เปลี่ยน `Citral` จาก 2.4 → **3.6** |
| **ผลรวมไม่ครบ** | ลดสารตัวใดก็ได้ลง เช่น `Bergamot` 18 → 15 |
| **Muddy Accord** | ลด `Iso E Super` เหลือ ~12 แล้วเกลี่ยไปสารอื่นให้ทุกกลุ่มอยู่ระหว่าง 5–20% |

## 5. การยึด Design System

| Token จาก DESIGN.md | ใช้ตรงไหนใน Prototype |
|---|---|
| `Vapor Mist #F3EFE7` | พื้นหลังหน้า |
| `Absolute Ink #20281F` | Hero panel, Command Bar, ชั้น Base ของพีระมิด |
| `Amber Glass #C0813A` | ปุ่มหลัก, ชั้น Top, กราฟกลุ่มเด่นที่สุด |
| `Botanical Sage #7E8F6E` | สถานะ PASS, กราฟ Spectrum |
| `Rose Attar #B15E6C` | ชั้น Heart ของพีระมิด |
| `Ember Warn #BD5A2E` | IFRA FAIL, Muddy Accord **เท่านั้น** |
| Font 3 บทบาท | Display (บรีฟกลิ่น) · Body (เนื้อหา) · Mono (ตัวเลข/ppm/%) |
| Signature Element | พีระมิดกลิ่นไล่ชั้นสี Top → Heart → Base |
| โมทีฟโมเลกุล | line-art มุมขวาบน opacity 6% |

**กฎที่ทำตาม:** ไม่มีตารางสารเคมีดิบเต็มจอ · ไม่แสดงทั้ง 100 กลุ่มพร้อมกัน · ปุ่ม disabled แสดงเหตุผลเสมอ · ไม่ใช้แดง/เขียวมาตรฐาน

## 6. ข้อจำกัดที่ต้องรู้ (Known Limitations)

| ข้อจำกัด | เหตุผล |
|---|---|
| **ค่าเคมีเป็นค่าสมมติทั้งหมด** | Rule Sheet ฉบับเต็มยังไม่ส่งมอบ (ความเสี่ยง R-01 ใน Test Plan) |
| แสดงสารเพียง 12 ตัว | ใช้แทนสูตรจริงที่มี 50–80 ตัว เพื่อให้สาธิต UI ได้ในหน้าเดียว |
| ไม่มีระบบล็อกอินจริง | F-08 ยังไม่ทำเป็น prototype — แสดงเป็นข้อความบน header เท่านั้น |
| ยังไม่มี What-If Diff View | F-12 อยู่ระดับ Should — จะทำใน v2 |
| ยังไม่ทดสอบ Accessibility เป็นทางการ | ต้องวัด contrast ตาม NFR-15 ก่อนถือว่าผ่าน |

> ⚠️ ค่าตัวเลขทั้งหมดในไฟล์นี้เป็น**ข้อมูลสมมติเพื่อสาธิต UI** ไม่ใช่ข้อมูลเคมีจริงของโครงการ
