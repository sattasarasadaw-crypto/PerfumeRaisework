## 3. สิ่งที่กดได้จริง (Interactive Elements)

| # | สิ่งที่ทำได้ | สาธิต FR/NFR อะไร |
|---|---|---|
| 0 | ⭐ **สลับความเข้มข้นของผลิตภัณฑ์** (EDT 12% / EDP 20% / Parfum 30%) — เปลี่ยนผลตรวจทั้งหมดทันทีโดยไม่ต้องแก้สูตร | FR-21, NFR-02 |
| 1 | **แก้ % ของสารแต่ละตัว** — ผลรวมอัปเดตทันที + แต่ละแถวแสดง `%ในขวด / เพดาน / ใช้ไปกี่ %` | FR-01, FR-22 |
| 2 | **ผลรวม ≠ 100%** → ตัวเลขเป็นสีแจ้งเตือน + แสดง "ขาดอีก X%" / "เกินมา X%" + **ปุ่มคำนวณถูกปิด** | FR-02, AC-01.2, AC-01.3 |
| 3 | **กดปุ่มคำนวณ** → Dashboard ปรากฏครบทุกส่วนทันที | FR-26, AC-07.1 |
| 4 | **แก้ % หลังคำนวณแล้ว** → ทุกอย่างคำนวณใหม่**อัตโนมัติ ไม่ต้องกดปุ่มซ้ำ** | FR-21, NFR-02, AC-05.3 |
| 5 | **ดันสารเกินเพดาน IFRA** (เช่น Citral > 3.0%) → เปลี่ยนเป็น **FAIL** + ชี้ชื่อสาร + ส่วนต่าง + **ช่องกรอกขึ้นขอบแดง** | FR-21, FR-22, AC-05.2 |
| 6 | **เมื่อ IFRA FAIL** → **ปุ่ม Export ถูกปิด** พร้อมแสดงเหตุผล | BR-02, AC-05.4 |
| 7 | **ปรับให้ทุกกลุ่มอยู่ระหว่าง 5–20%** → แจ้งเตือน **Muddy Accord** + ค่าความเสี่ยง % | FR-23, BR-04, AC-06.1 |
| 8 | **กด "ขอคำแนะนำปรับลด"** → เปิดกล่องบอกว่าควรดันกลุ่มไหนขึ้น/ลง | FR-24 |
| 9 | **กดที่ค่า Longevity / Sillage** → เปิดกล่อง**อธิบายที่มาของการคำนวณ** | NFR-08, AC-07.4 |
| 10 | **สลับโทนบรีฟ** 3 แบบ (เชิงเคมี / การตลาด / English) | FR-18 |
| 11 | **กด chip ใน Command Bar** หรือพิมพ์คำถาม → แสดงตารางเจาะลึก | FR-29 |
| 12 | **กด "ดูทั้งหมด 100 กลุ่ม"** → แสดงรายการกลุ่มทั้งหมดที่สูตรแตะ | FR-28 |

## 4. ข้อมูลที่ใช้ — สูตรจริงจากคลังวัตถุดิบ

Prototype นี้ใช้สูตรตัวอย่าง **EDP-001 "Amber Sage"** — 26 สาร ผลรวม 100.00%
รายละเอียดเต็มและที่มาของข้อมูล: [`sample-formula.md`](sample-formula.md)

| ข้อมูล | สถานะ |
|---|---|
| ชื่อสาร + CAS Number | ✅ **จริง** — จากคลังวัตถุดิบของโครงการ (127 สาร) |
| เพดาน IFRA Category 4 | ✅ **จริง** — จาก IFRA 51st Amendment (มีเพดานตัวเลข 8 ตัวในสูตรนี้) |
| Micro-Cluster / ODT / Synergy | ⚠️ **สมมติ** — รอ Rule Sheet |
| ราคาวัตถุดิบ | ⚠️ **ดัชนี tier 1–4** — ราคาจริงเป็นข้อมูลภายใน ไม่อยู่ใน repo นี้ |

## 5. ⭐ สลับความเข้มข้นเดียว = สาธิตได้ครบ 3 ฟีเจอร์

เพดาน IFRA คิดจาก **ผลิตภัณฑ์สำเร็จรูป** ไม่ใช่หัวน้ำหอมเข้มข้น → `%ในขวด = %สูตร × ความเข้มข้น`
กดปุ่มเดียวจึงเปลี่ยนผลตรวจทั้งระบบโดยไม่ต้องแก้สูตรเลย

| ปุ่ม | IFRA | ODT | Muddy | สาธิตอะไร |
|---|---|---|---|---|
| **EDT 12%** | ✅ PASS (Citral 56% ของเพดาน) | ⚠️ **ตัดออก 3 ตัว** — Limonene, Ethylene Brassylate, Evernyl | ✅ ปลอดภัย | **ฟีเจอร์ ODT** — เจือจางลง สารอ่อนหลุดต่ำกว่าเกณฑ์ที่จมูกรับรู้ |
| **EDP 20%** *(ค่าเริ่มต้น)* | ✅ PASS (Citral **93%** ของเพดาน) | ✅ ไม่มีสารถูกตัด | ✅ ปลอดภัย | **สถานะสมบูรณ์** — สูตรที่ใช้งานได้จริง |
| **Parfum 30%** | ❌ **FAIL** — Citral 0.840% เกินเพดาน 0.6% อยู่ 0.24% | ✅ ไม่มีสารถูกตัด | ✅ ปลอดภัย | **ฟีเจอร์ IFRA + BR-02** — ปุ่ม Export ถูกปิดทันที |

> 💡 **ข้อสรุปเชิงธุรกิจที่ Prototype นี้ทำให้เห็น:** สูตรเดียวกันขายเป็น EDT และ EDP ได้ แต่**ยกไปทำ Parfum 30% ไม่ได้**
> ถ้าอยากทำ Parfum ต้องลด Citral จาก 2.80% เหลือไม่เกิน **2.00%** — เป็นการตัดสินใจที่เดิมต้องรอผสมจริงถึงจะรู้

### วิธีลองสถานะอื่นเพิ่มเติม

| อยากเห็น | ทำอย่างไร |
|---|---|
| **ผลรวมไม่ครบ 100%** | ลดสารตัวใดก็ได้ เช่น `Hedione` 12.00 → 9.00 |
| **IFRA FAIL ที่ EDP** | ดัน `Citral` จาก 2.80 → **3.20** |
| **Muddy Accord** | ลด `Iso E Super` เหลือ ~10 แล้วเกลี่ยส่วนต่างไปกลุ่มอื่นให้ทุกกลุ่มอยู่ระหว่าง 5–20% |

| `Amber Glass #C0813A` | ปุ่มหลัก, ชั้น Top, กราฟกลุ่มเด่นที่สุด |

## 6. ข้อจำกัดที่ต้องรู้ (Known Limitations)

| ข้อจำกัด | เหตุผล |
|---|---|
| **Micro-Cluster, ODT และค่าปฏิกิริยาเป็นค่าสมมติ** | Rule Sheet ฉบับเต็มยังไม่ส่งมอบ (ความเสี่ยง R-01 ใน Test Plan) — *แต่ชื่อสาร CAS และเพดาน IFRA เป็นข้อมูลจริง* |
| แสดงสาร 26 ตัว | สูตรจริงมี 50–80 ตัว — 26 ตัวพอสำหรับสาธิตครบทุกชั้นและทุกฟีเจอร์ |
| ยังไม่บล็อกสารที่ IFRA ห้ามใช้ (PROHIBITION) | พบ 3 ตัวในคลัง (6-methyl Coumarin, Musk Ambrette, Musk Xylol) — FR-21/FR-22 ปัจจุบันครอบคลุมเฉพาะ RESTRICTION ควรเพิ่มเป็น requirement ใหม่ |
| ไม่มีระบบล็อกอินจริง | F-08 ยังไม่ทำเป็น prototype — แสดงเป็นข้อความบน header เท่านั้น |
| ยังไม่มี What-If Diff View | F-12 อยู่ระดับ Should — จะทำใน v2 |
| ยังไม่ทดสอบ Accessibility เป็นทางการ | ต้องวัด contrast ตาม NFR-15 ก่อนถือว่าผ่าน |

> ⚠️ ค่าตัวเลขทั้งหมดในไฟล์นี้เป็น**ข้อมูลสมมติเพื่อสาธิต UI** ไม่ใช่ข้อมูลเคมีจริงของโครงการ
