## 2. คำอธิบายรายฟีเจอร์

### 🔴 Must have — ขอบเขต MVP

#### F-01 การจัดการสูตรน้ำหอม
ผู้ใช้สร้างสูตรใหม่โดยเลือกสารจากคลัง (ค้นด้วยชื่อสามัญ, CAS Number หรือรหัส RM-xxx) แล้วระบุสัดส่วน % ของแต่ละตัว ระบบตรวจว่าผลรวมเท่ากับ 100% ก่อนอนุญาตให้คำนวณ — ถ้าไม่ครบต้องแจ้งส่วนต่างให้เห็นชัด สูตรที่สร้างแล้วบันทึก เปิด และแก้ไขซ้ำได้
> **ทำไมถึงเป็น Must:** ไม่มีฟีเจอร์นี้ = ไม่มี input ให้ระบบทั้งระบบ

#### F-02 Engine A — เครื่องคำนวณฟิสิกส์เคมี
หัวใจของทั้งระบบ ทำงานเป็นลำดับ: ระบุ Micro-Cluster ของแต่ละสาร → คำนวณน้ำหนัก % ของกลุ่ม → ดึงค่า Synergy / Suppression / Evaporation Shift จาก Group Interaction Matrix ที่คำนวณล่วงหน้า → คำนวณ Time-Series การระเหยเพื่อแยก Top / Heart / Base → สรุปเป็นค่า Longevity และ Sillage Index
> **ข้อจำกัดสำคัญ:** ต้องเป็น **Deterministic** — input เดิมให้ผลเดิมทุกครั้ง ห้ามมีค่าสุ่มใดๆ (NFR-03)

#### F-03 Olfactory Threshold Filter
เทียบความเข้มข้นที่ระเหยจริงในอากาศ (ppm) ของสารแต่ละตัว กับค่า **Olfactory Detection Threshold (ODT)** ของสารนั้น สารที่ต่ำกว่าเกณฑ์จะถูกตัดออกจากการเขียนบรีฟกลิ่น เพราะจมูกมนุษย์ไม่รับรู้อยู่ดี
> **สำคัญ:** ต้อง**แสดงรายการสารที่ถูกตัดให้ผู้ใช้เห็น**พร้อมเหตุผล — เพราะนั่นคือต้นทุนที่ผู้ใช้จ่ายไปเปล่าๆ และเป็นข้อมูลตัดสินใจ ไม่ใช่ข้อมูลที่ควรซ่อน (สอดคล้อง NFR-08 Explainability)

#### F-04 Engine B — บรีฟบรรยายกลิ่นอัตโนมัติ
แปลงผลลัพธ์ตัวเลขจาก Engine A ให้กลายเป็นคำบรรยายกลิ่นที่อ่านเข้าใจง่าย แยกเป็นชั้น Top / Heart / Base พร้อมชื่อกลุ่มและ %
> **เส้นแบ่งที่ห้ามข้าม:** Engine B **ไม่มีสิทธิ์สร้างหรือแก้ไขตัวเลขใดๆ** และห้ามอ้างถึงสารที่ถูก ODT ตัดไปแล้ว — นี่คือกลไกกัน Hallucination ของทั้งระบบ

#### F-05 IFRA Compliance Check
ตรวจเพดานความเข้มข้นตาม IFRA 51st Amendment ทั้งรายสารและรายกลุ่มสาร ทุกครั้งที่ผู้ใช้เปลี่ยนสัดส่วน แสดงผลเป็น PASS / FAIL พร้อมส่วนต่างและชื่อสารที่เกิน
> **ทำไมถึงเป็น Must:** สูตรที่ผิด IFRA = ผลิตขายไม่ได้เลย ไม่ว่ากลิ่นจะดีแค่ไหน

#### F-06 Muddy Accord Detection
ตรวจว่าสูตร**ไม่มี**กลุ่มใดสูงกว่า 20% **และไม่มี**กลุ่มใดต่ำกว่า 5% ซึ่งหมายถึงกลิ่นกระจายเท่ากันหมดจนไร้มิติ แล้วแสดงเป็นค่าความเสี่ยง 0–100%
> **คุณค่าทางธุรกิจ:** ปัญหานี้คือสาเหตุที่นักปรุงต้อง "ทิ้งทั้งสูตรแล้วเริ่มใหม่" — จับได้บนหน้าจอ = ประหยัดทั้งเวลาและวัตถุดิบ

#### F-07 Dashboard สรุปผลสูตร
หน้าจอหลักที่ผู้ใช้ใช้เวลาด้วยมากที่สุด แสดงผลอัตโนมัติทันทีที่คำนวณเสร็จ ประกอบด้วย บรีฟกลิ่น + พีระมิดกลิ่น + สถานะ IFRA + Longevity/Sillage + คำเตือนความเสี่ยง
> **เกณฑ์คุณภาพ:** ผลสรุปหลักต้องอ่านครบภายใน 1 หน้าจอโดยไม่ต้องเลื่อน (NFR-14)

#### F-08 บัญชีผู้ใช้และการกำกับข้อมูล
เข้าสู่ระบบด้วยบัญชีผู้ใช้, บันทึก Audit Log ทุกการเข้าใช้และการแก้ไขสูตร, และให้ผู้ใช้จัดการความยินยอมเรื่องข้อมูลส่วนบุคคลได้เอง
> **ทำไมถึงเป็น Must ทั้งที่ไม่ใช่ฟีเจอร์เด่น:** สูตรน้ำหอม = ความลับทางการค้ามูลค่าสูง (NFR-09) และเป็นข้อบังคับตาม พ.ร.บ.คอมพิวเตอร์ ม.26 (เก็บ Log ≥ 90 วัน) กับ PDPA (NFR-10, NFR-11)

### 🟠 Should have — เพิ่มคุณค่ามาก แต่ระบบยังทำงานได้ถ้าไม่มี

#### F-09 Fine-tune ระดับรายสาร
ปรับผลลัพธ์ที่ได้จากระดับกลุ่ม (Micro-Cluster) ให้ละเอียดขึ้นด้วยข้อมูล Master Code รายสาร (MW, Vapor Pressure, LogP, Receptor tag) — ถ้าไม่มี ระบบยังให้ผลระดับกลุ่มที่ใช้งานได้ แค่ความละเอียดต่ำกว่า

#### F-10 คำแนะนำแก้ไขและเตือน Scent Drift
เมื่อพบ Muddy Accord ระบบแนะนำช่วงสัดส่วนที่ควรปรับพร้อมชี้ตัวการ และเตือนเมื่อการแก้สูตรทำให้กลิ่นเบี่ยงจากบรีฟตั้งต้น
> *หมายเหตุ:* เกณฑ์ตัวเลขของ Scent Drift ยังเป็น Open Issue (OI-01) รอ Rule Sheet ฉบับเต็ม

#### F-11 Visualization ขั้นสูง + Command Bar
กราฟสัดส่วน Micro-Cluster ทั้งหมด และช่อง Command Bar ให้พิมพ์ถามเจาะลึก เช่น *"ขอตารางต้นทุนต่อกิโลกรัม"* หรือ *"สารตัวไหนกลบ Top Note อยู่?"*

#### F-12 What-If Simulation
สลับสารตัวหนึ่งเป็นสารอื่นในกลุ่มเดียวกัน (เช่น กุหลาบ 1 → กุหลาบ 2) แล้วระบบคำนวณ**เฉพาะจุดต่าง** แสดงเป็น Diff View เทียบ กลิ่น / Longevity / Sillage / IFRA / ต้นทุน
> **จุดขายเชิงกลยุทธ์:** นี่คือฟีเจอร์ที่ทำให้รอบทดลองในแล็บลดจาก ~70 เหลือ 3–5 ครั้ง

#### F-13 Member-Level Distinctiveness
แต่ละ Micro-Cluster แสดงรายชื่อสารสมาชิกในกลุ่ม โดยไฮไลต์สารที่อยู่ในบรีฟและแสดงสารอื่นด้วยโทนจาง พร้อม Distinctiveness Card บอกเอกลักษณ์เฉพาะตัวของแต่ละสาร
> **ปิดช่องว่างอะไร:** สารที่อยู่กลุ่มเดียวกันจะมีคุณสมบัติหลักเหมือนกัน ระบบจึงแยกไม่ออก — ชั้นนี้คือที่ที่มนุษย์เข้ามาตัดสินใจเรื่อง "นัวส์"

#### F-14 การคำนวณต้นทุนสูตร
คำนวณต้นทุนวัตถุดิบต่อกิโลกรัม และชี้ว่าสารตัวไหนกินสัดส่วนต้นทุนสูงสุด

#### F-15 ประวัติเวอร์ชันสูตร
เก็บประวัติทุกเวอร์ชันของสูตรพร้อมวันเวลา ผู้แก้ไข และสิ่งที่เปลี่ยน — ย้อนกลับไปเวอร์ชันเดิมได้เมื่อแก้แล้วแย่ลง

### 🟡 Could have — มีก็ดี ทำเมื่อมีเวลาเหลือ

#### F-16 นำเข้า / ส่งออกข้อมูล
Import สูตรจาก CSV/Excel (สำหรับผู้ใช้ที่มีสูตรเดิมอยู่แล้ว) และ Export ผลลัพธ์เป็นรายงาน PDF/CSV
> *ข้อบังคับ:* สูตรที่ IFRA = FAIL ห้าม Export เป็นรายงานฉบับสมบูรณ์ (BR-02)

#### F-17 คลังสารส่วนตัว (Private Registry)
ผู้ใช้เพิ่มและจัดการสารเฉพาะของตัวเองที่ไม่มีในคลังกลาง
