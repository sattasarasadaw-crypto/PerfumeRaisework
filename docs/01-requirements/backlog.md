## 4. User Stories (เฉพาะรายการระดับสูงที่เข้า MVP)

> รูปแบบ: `ในฐานะ [ใคร] ฉันต้องการ [ทำอะไรได้] เพื่อที่จะ [ได้ประโยชน์อะไร]`

| # | User Story | FR ที่ครอบคลุม |
|---|---|---|
| US-01 | ในฐานะ**นักปรุงน้ำหอม** ฉันต้องการ**ป้อนสูตรพร้อมสัดส่วนของสารแต่ละตัว** เพื่อที่จะ**ให้ระบบคำนวณผลลัพธ์ของสูตรนั้นได้** | FR-01, FR-02, FR-03 |
| US-02 | ในฐานะ**นักปรุงน้ำหอม** ฉันต้องการ**เห็นคำบรรยายกลิ่นของสูตรที่ระบบคำนวณให้** เพื่อที่จะ**รู้ว่าสูตรนี้ให้กลิ่นแบบไหนโดยไม่ต้องผสมจริง** | FR-12, FR-18, FR-20, FR-27 |
| US-03 | ในฐานะ**นักปรุงน้ำหอม** ฉันต้องการ**รู้ทันทีว่าสูตรผ่านเกณฑ์ IFRA หรือไม่** เพื่อที่จะ**ไม่เสียเวลาผสมสูตรที่ผิดกฎหมายตั้งแต่แรก** | FR-21, FR-22 |
| US-04 | ในฐานะ**นักปรุงน้ำหอม** ฉันต้องการ**ถูกเตือนเมื่อสูตรเสี่ยงกลิ่นตีกัน (Muddy Accord)** เพื่อที่จะ**แก้สัดส่วนก่อนลงแล็บ ไม่ต้องทิ้งทั้งสูตร** | FR-23 |
| US-05 | ในฐานะ**นักปรุงน้ำหอม** ฉันต้องการ**รู้ว่าสารตัวไหนถูกตัดออกเพราะจมูกไม่รับรู้** เพื่อที่จะ**ตัดต้นทุนที่จ่ายไปโดยเปล่าประโยชน์ออกจากสูตร** | FR-16, FR-17 |
| US-06 | ในฐานะ**นักปรุงน้ำหอม** ฉันต้องการ**เห็นค่าความทน (Longevity) และการกระจายตัว (Sillage)** เพื่อที่จะ**ตอบลูกค้าได้ว่าน้ำหอมนี้ติดทนกี่ชั่วโมง** | FR-13, FR-14 |
| US-07 | ในฐานะ**นักปรุงน้ำหอม** ฉันต้องการ**เห็นผลทั้งหมดรวมอยู่ในหน้าเดียวทันทีที่คำนวณเสร็จ** เพื่อที่จะ**ตัดสินใจได้เร็วโดยไม่ต้องเปิดหลายหน้าจอ** | FR-26 |
| US-08 | ในฐานะ**เจ้าของสูตร** ฉันต้องการ**ให้สูตรของฉันถูกเก็บเป็นความลับและตรวจสอบย้อนหลังได้ว่าใครแก้อะไร** เพื่อที่จะ**ปกป้องทรัพย์สินทางปัญญาของฉัน** | FR-04, FR-37, FR-38, FR-39 |
