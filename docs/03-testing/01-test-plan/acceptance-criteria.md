## F-01 การจัดการสูตรน้ำหอม

### AC-01.1 สร้างสูตรและระบุสัดส่วน `FR-01`
```gherkin
Given  นักปรุงน้ำหอมเข้าสู่ระบบแล้วและอยู่ที่หน้าสร้างสูตรใหม่
When   เพิ่มสารเข้าสูตรและระบุสัดส่วน % ของแต่ละตัว
Then   ระบบต้องแสดงรายการสารทั้งหมดพร้อมสัดส่วนที่กรอก
And    ระบบต้องแสดงผลรวม % ปัจจุบันให้เห็นตลอดเวลาโดยไม่ต้องกดปุ่มใด
```

### AC-01.2 บล็อกการคำนวณเมื่อผลรวมไม่เท่ากับ 100% `FR-02`
```gherkin
Given  สูตรมีผลรวมสัดส่วนเท่ากับ 97.5%
When   ผู้ใช้พยายามกดปุ่ม "คำนวณสูตร"
Then   ระบบต้องไม่เริ่มคำนวณ
And    ต้องแสดงข้อความระบุส่วนต่างที่ขาด คือ "ขาดอีก 2.5%"
And    ปุ่ม "คำนวณสูตร" ต้องอยู่ในสถานะปิดใช้งาน (disabled)
```

### AC-01.3 แจ้งเตือนเมื่อผลรวมเกิน 100% `FR-02`
```gherkin
Given  สูตรมีผลรวมสัดส่วนเท่ากับ 103%
When   ผู้ใช้ดูแถบสรุปผลรวม
Then   ระบบต้องแสดงข้อความว่า "เกินมา 3%"
And    ต้องใช้สีแจ้งเตือนตาม token ที่กำหนดใน DESIGN.md
```

### AC-01.4 ค้นหาสารจากคลัง `FR-03`
```gherkin
Given  ผู้ใช้อยู่ที่ช่องค้นหาสาร
When   พิมพ์ CAS Number ที่มีอยู่จริงในคลัง
Then   ระบบต้องแสดงสารที่ตรงกันภายใน 1 วินาที
And    ผลลัพธ์ต้องแสดงทั้งชื่อสามัญ, CAS Number และรหัสภายใน (RM-xxx)
```

### AC-01.5 บันทึกและเปิดสูตรเดิม `FR-04`
```gherkin
Given  ผู้ใช้คำนวณสูตรเสร็จแล้วและพอใจกับผลลัพธ์
When   กดปุ่ม "บันทึกสูตร"
Then   ระบบต้องบันทึกสูตรพร้อมสัดส่วนทั้งหมด
And    เมื่อเปิดสูตรนั้นขึ้นมาใหม่ ต้องได้สารและสัดส่วนเดิมครบทุกตัว
```

## F-02 Engine A — เครื่องคำนวณฟิสิกส์เคมี

### AC-02.1 ระบุ Micro-Cluster อัตโนมัติ `FR-07`
```gherkin
Given  สูตรมีสารที่มี Master Code ครบทุกตัว
When   ระบบเริ่มคำนวณ
Then   สารทุกตัวต้องถูกจับคู่กับ Micro-Cluster ได้ครบ 100%
And    ถ้ามีสารตัวใดที่ยังไม่ได้ระบุกลุ่ม ระบบต้องแจ้งชื่อสารนั้นและหยุดการคำนวณ
```

### AC-02.2 ผลลัพธ์ต้องทำซ้ำได้ (Deterministic) `NFR-03`
```gherkin
Given  สูตรเดิมที่ไม่มีการแก้ไขใดๆ
When   ผู้ใช้สั่งคำนวณซ้ำเป็นครั้งที่สอง
Then   ผลลัพธ์ทุกค่า (Synergy, Suppression, Longevity, Sillage) ต้องเท่าเดิมทุกตัวเลข
And    ค่าคำบรรยายกลิ่นต้องเหมือนเดิม
```

### AC-02.3 แสดงค่า Longevity และ Sillage `FR-13, FR-14`
```gherkin
Given  ระบบคำนวณสูตรเสร็จเรียบร้อยแล้ว
When   ผู้ใช้ดูที่การ์ดคุณสมบัติกลิ่นบน Dashboard
Then   ต้องแสดงค่า Longevity เป็นช่วงชั่วโมง เช่น "6.5 – 8.0 ชม."
And    ต้องแสดง Sillage Index เป็นหนึ่งใน good / moderate / intimate
```

### AC-02.4 ประสิทธิภาพการคำนวณ `NFR-01`
```gherkin
Given  สูตรที่มีสาร 80 ตัว
When   ผู้ใช้กดปุ่ม "คำนวณสูตร"
Then   ผลลัพธ์ครบทุกส่วนต้องปรากฏบน Dashboard ภายใน 500 มิลลิวินาที
```

## F-03 Olfactory Threshold Filter

### AC-03.1 ตัดสารที่ต่ำกว่า ODT ออกจากบรีฟ `FR-16, FR-17`
```gherkin
Given  สูตรมีสารตัวหนึ่งที่คำนวณแล้วมีความเข้มข้นต่ำกว่าค่า ODT ของสารนั้น
When   ระบบสร้างคำบรรยายกลิ่น
Then   คำบรรยายกลิ่นต้องไม่กล่าวถึงสารตัวนั้นเลย
```

### AC-03.2 แสดงรายการสารที่ถูกตัดให้ผู้ใช้ทราบ `FR-17, NFR-08`
```gherkin
Given  มีสาร 3 ตัวถูกตัดออกเพราะต่ำกว่าค่า ODT
When   ผู้ใช้ดู Dashboard
Then   ต้องมีส่วนแสดงรายการสารที่ถูกตัดทั้ง 3 ตัว
And    แต่ละตัวต้องแสดงเหตุผล พร้อมค่า ppm ที่คำนวณได้ เทียบกับค่า ODT เกณฑ์
And    ต้องระบุชัดว่าสารเหล่านี้ยังคงถูกนับในการคำนวณ IFRA และต้นทุน
```

## F-04 Engine B — บรีฟบรรยายกลิ่นอัตโนมัติ

### AC-04.1 สร้างคำบรรยายแยกชั้น `FR-18, FR-20`
```gherkin
Given  Engine A คำนวณโครงสร้าง Top / Heart / Base เสร็จแล้ว
When   Engine B สร้างคำบรรยายกลิ่น
Then   ต้องแสดงคำบรรยายแยกเป็น 3 ชั้น คือ Top Accord, Heart Accord และ Base Accord
And    แต่ละชั้นต้องระบุชื่อกลุ่มกลิ่นพร้อม % ที่มาจาก Engine A
```

### AC-04.2 Engine B ห้ามสร้างตัวเลขเอง `FR-19, BR-05`
```gherkin
Given  Engine A ส่งค่า Longevity เท่ากับ "6.5 – 8.0 ชม."
When   Engine B เขียนคำบรรยาย
Then   ตัวเลขทุกตัวที่ปรากฏในคำบรรยายต้องตรงกับค่าที่ Engine A ส่งมาเป๊ะ
And    ต้องไม่มีตัวเลขใดที่ไม่ปรากฏใน output ของ Engine A
And    ต้องไม่กล่าวถึงสารที่ถูก Threshold Filter ตัดออกไปแล้ว
```

### AC-04.3 แจ้งผู้ใช้ว่าเนื้อหาสร้างโดย AI `NFR-12`
```gherkin
Given  ระบบแสดงคำบรรยายกลิ่นบน Dashboard
When   ผู้ใช้อ่านส่วนคำบรรยาย
Then   ต้องมีข้อความกำกับชัดเจนว่าคำบรรยายนี้สร้างโดย AI
And    ต้องระบุว่าต้องผ่านการยืนยันจากนักปรุงน้ำหอมก่อนนำไปใช้จริง
```

## F-05 IFRA Compliance Check

### AC-05.1 กรณีผ่านเกณฑ์ `FR-21, FR-22`
```gherkin
Given  สูตรที่ทุกสารอยู่ต่ำกว่าเพดาน IFRA 51st Amendment
When   ระบบตรวจสอบความสอดคล้อง
Then   ต้องแสดงสถานะ "PASS"
And    ต้องแสดงระยะห่างจากเพดานที่ยังเหลืออยู่ของสารที่ใกล้เพดานที่สุด
```

### AC-05.2 กรณีไม่ผ่านเกณฑ์ `FR-21, FR-22`
```gherkin
Given  สูตรมีสารตัวหนึ่งที่มีความเข้มข้นเกินเพดาน IFRA
When   ระบบตรวจสอบความสอดคล้อง
Then   ต้องแสดงสถานะ "FAIL"
And    ต้องระบุชื่อสารที่เกินเพดาน
And    ต้องแสดงส่วนต่างที่เกินเป็นหน่วย ppm หรือ %
```

### AC-05.3 ตรวจซ้ำอัตโนมัติแบบ Real-time `FR-21, NFR-02`
```gherkin
Given  ผลตรวจ IFRA ปัจจุบันเป็น FAIL
When   ผู้ใช้ลดสัดส่วนของสารที่เกินจนต่ำกว่าเพดาน
Then   ระบบต้องตรวจ IFRA ใหม่โดยอัตโนมัติ ผู้ใช้ไม่ต้องกดปุ่มคำนวณซ้ำ
And    สถานะต้องเปลี่ยนเป็น "PASS" ภายใน 300 มิลลิวินาที
```

### AC-05.4 บล็อกการ Export เมื่อยัง FAIL `BR-02, FR-30`
```gherkin
Given  สูตรมีสถานะ IFRA เป็น FAIL
When   ผู้ใช้พยายามกดปุ่ม Export รายงานฉบับสมบูรณ์
Then   ปุ่มต้องอยู่ในสถานะปิดใช้งาน
And    ต้องแสดงเหตุผลว่าสูตรยังไม่ผ่านเกณฑ์ IFRA
```

## F-06 Muddy Accord Detection

### AC-06.1 ตรวจพบความเสี่ยง `FR-23, BR-04`
```gherkin
Given  สูตรที่ไม่มีกลุ่มกลิ่นใดมีสัดส่วนสูงกว่า 20% และไม่มีกลุ่มใดต่ำกว่า 5%
When   ระบบวิเคราะห์โครงสร้างกลุ่ม
Then   ต้องแจ้งเตือน Muddy Accord Risk
And    ต้องแสดงค่าความเสี่ยงเป็นตัวเลขในช่วง 0–100%
```

### AC-06.2 กรณีไม่มีความเสี่ยง `FR-23, BR-04`
```gherkin
Given  สูตรที่มีกลุ่มกลิ่นหนึ่งมีสัดส่วน 35% และอีกกลุ่มมีสัดส่วน 3%
When   ระบบวิเคราะห์โครงสร้างกลุ่ม
Then   ต้องไม่แจ้งเตือน Muddy Accord
And    ค่าความเสี่ยงที่แสดงต้องอยู่ในระดับต่ำ
```

## F-07 Dashboard สรุปผลสูตร

### AC-07.1 แสดงผลอัตโนมัติทันทีที่คำนวณเสร็จ `FR-26`
```gherkin
Given  ผู้ใช้กดปุ่ม "คำนวณสูตร" และระบบคำนวณเสร็จแล้ว
When   หน้า Dashboard ปรากฏขึ้น
Then   ต้องแสดงครบทั้ง 5 ส่วนโดยผู้ใช้ไม่ต้องกดอะไรเพิ่ม ได้แก่
       คำบรรยายกลิ่น, พีระมิดกลิ่น, สถานะ IFRA, ค่า Longevity/Sillage และคำเตือนความเสี่ยง
```

### AC-07.2 พีระมิดกลิ่น `FR-27`
```gherkin
Given  ระบบคำนวณโครงสร้าง Top / Heart / Base เสร็จแล้ว
When   ผู้ใช้ดูส่วนพีระมิดกลิ่น
Then   ต้องแสดงครบทั้ง 3 ชั้น
And    แต่ละชั้นต้องแสดงชื่อกลุ่มกลิ่นเรียงตาม % จากมากไปน้อย
And    ต้องแสดง % ของแต่ละกลุ่มกำกับไว้
```

### AC-07.3 อ่านผลสรุปได้ในหน้าจอเดียว `NFR-14`
```gherkin
Given  ผู้ใช้เปิด Dashboard บนหน้าจอความละเอียด 1440x900
When   หน้าโหลดเสร็จ
Then   คำบรรยายกลิ่น, สถานะ IFRA และคำเตือนความเสี่ยง ต้องมองเห็นได้ครบโดยไม่ต้องเลื่อนหน้าจอ
```

### AC-07.4 ความสามารถในการอธิบายที่มา `NFR-08`
```gherkin
Given  Dashboard แสดงค่า Longevity เท่ากับ "6.5 – 8.0 ชม."
When   ผู้ใช้คลิกที่ค่านั้น
Then   ระบบต้องแสดงที่มาของการคำนวณ ได้แก่ กลุ่มกลิ่นและสารที่มีผลต่อค่านี้มากที่สุด
```

## F-08 บัญชีผู้ใช้และการกำกับข้อมูล

### AC-08.1 แยกข้อมูลตามบัญชี `FR-37, NFR-09`
```gherkin
Given  ผู้ใช้ A และผู้ใช้ B ต่างมีสูตรของตัวเองในระบบ
When   ผู้ใช้ A เข้าสู่ระบบ
Then   ต้องเห็นเฉพาะสูตรของผู้ใช้ A เท่านั้น
And    ต้องไม่สามารถเข้าถึงสูตรของผู้ใช้ B ได้ไม่ว่าด้วยวิธีใด
```

### AC-08.2 บันทึก Audit Log `FR-38, NFR-10`
```gherkin
Given  ผู้ใช้แก้ไขสัดส่วนของสูตรแล้วบันทึก
When   ผู้ดูแลระบบตรวจสอบ Audit Log
Then   ต้องพบรายการที่ระบุ ผู้แก้ไข, สิ่งที่เปลี่ยน และวันเวลา
And    Log ต้องถูกเก็บรักษาไว้อย่างน้อย 90 วัน
```

### AC-08.3 การจัดการความยินยอม `FR-39, NFR-11`
```gherkin
Given  ผู้ใช้เข้าใช้งานระบบเป็นครั้งแรก
When   ระบบขอเก็บข้อมูลส่วนบุคคล
Then   ต้องแสดงคำขอความยินยอมพร้อมระบุว่าจะเก็บข้อมูลอะไรและใช้ทำอะไร
And    ผู้ใช้ต้องสามารถถอนความยินยอมได้ในภายหลังจากหน้าตั้งค่าบัญชี
And    เมื่อถอนความยินยอมแล้ว ระบบต้องหยุดใช้ข้อมูลนั้นทันที
```
